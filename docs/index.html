Install / Download

지금 바로 설치.

ESP32-S3의 ROM 부트매니저를 사용합니다. USB 케이블과 Chrome 또는 Edge가 필요합니다.

Browser installer

브라우저에서 설치

기기를 USB로 연결한 뒤 버튼을 누르면 부트매니저가 자동으로 다운로드 모드로 전환하고 펌웨어를 기록합니다.

Chrome 또는 Edge에서 HTTPS로 열어주세요. 이 브라우저에서는 Web Serial을 사용할 수 없습니다.
