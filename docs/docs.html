GNBD MINI·radio UI Editor v0.1.0 beta

브라우저에서 320 × 170 라디오 화면을 직접 그리고, 저장하는 순간 기기에 적용되는 런타임 UI 에디터입니다.

A runtime UI editor for the 320 × 170 radio screen — design in the browser and the radio picks it up the moment you save.

아직 부족한 점 WIP

기능이 많이 부족하고 미흡한 부분이 많습니다. 일부 기능은 동작하지 않거나 의도와 다르게 보일 수 있습니다. 중요한 레이아웃은 반드시 다운로드로 백업해 두세요.

Many features are still missing and there are rough edges. Some functions may not work or may look wrong. Always keep a download backup of important layouts.

접속 · 허브 http://<radio-ip>/에서 UI Editor를 선택하거나 /ui/로 바로 들어갑니다. Open · go to http://<radio-ip>/ and choose UI Editor, or open /ui/ directly.

1. 개요1. Overview

이 에디터는 펌웨어가 그리는 화면을 데이터로 정의합니다. 화면에 놓은 요소(위젯)는 좌표·크기·색·바인딩을 가지며, 저장하면 기기 LittleFS에 텍스트 레이아웃으로 기록되어 다음 프레임부터 곧바로 반영됩니다. 재부팅도, 펌웨어 재빌드도 필요 없습니다.

  • FM / AM / SSB 각각 별도 레이아웃
  • 모든 변경은 기기 저장 즉시 반영
  • 테마(색상)도 같은 파일에 포함되어 함께 적용
  • 마음에 안 들면 UI List에서 이전 레이아웃으로 되돌리기
참고: 에디터가 다루는 것은 화면 구성뿐입니다. 볼륨·밴드·스캔처럼 실제 동작은 기기의 MENU/SETTINGS에서 조작합니다.

The editor describes the firmware-drawn screen as data. Each widget carries a position, size, color and binding; saving writes a text layout to the radio's LittleFS and the very next frame uses it. No reboot, no firmware rebuild.

  • FM / AM / SSB have independent layouts
  • Changes apply immediately after saving
  • Theme colors are stored in the same file
  • Roll back anytime with UI List
Note: the editor only controls appearance. Radio behaviour (volume, band, scanning) is still handled by the device's MENU/SETTINGS.

4-2. 좌표 규칙4-2. Coordinate rules

  • 원점 (0,0)은 왼쪽 위, x는 오른쪽, y는 아래로 증가 / origin is top-left
  • 화면 밖 좌표도 저장은 되지만 잘려 보입니다 / off-screen widgets are clipped
  • 정렬 l/c/r은 위젯 박스 기준이므로 r은 글자 끝이 박스 오른쪽에 붙습니다 / alignment is relative to the widget box
좌표가 안 맞게 보이는 이유 / Why text looks misaligned:
오른쪽 정렬(r)은 위젯의 오른쪽 끝이 기준입니다. 드래그한 위치는 왼쪽 끝이므로, 같은 좌표라도 글자가 왼쪽으로 밀려 보입니다. 대부분 왼쪽 정렬로 바꾸면 해결됩니다.
Right alignment anchors the right edge of the widget box, while you drag the left edge. Switching to left alignment makes the drag position match the text.

5. 레이아웃 모드5. Layout modes

FM / AM / SSB는 완전히 별개의 레이아웃입니다. 탭을 바꾸면 캔버스 내용과 레이어 목록이 모두 교체됩니다. 한 모드에서 지운 위젯은 다른 모드에 영향을 주지 않습니다.

  • 각 레이아웃은 저장 시 하나의 파일에 함께 기록됩니다.
  • 위젯별 모드 제한도 가능합니다(속성의 modes 값, 1=FM 2=AM 4=SSB).
  • 기본 화면 위에 현재 모드 마스크와 맞는 위젯만 그려집니다.

FM / AM / SSB are separate layouts. Changing the tab swaps both the canvas and the layer list. Deleting a widget in one mode does not touch the others.

  • All three layouts are saved into one file.
  • Widgets can be restricted by mode mask (1=FM, 2=AM, 4=SSB).
  • Only widgets matching the current mode are drawn.

6-2. 크기조절 Resize

선택하면 8개의 파란 핸들이 나타납니다. 모서리 4개 + 변 4개이며, 어느 방향으로든 끌어서 크기를 바꿀 수 있습니다. 왼쪽/위쪽 핸들을 끌면 위치도 함께 이동합니다.

  • 최소 크기: 8 × 4 px
  • 화면(320 × 170) 밖으로 나가지 않음
  • 스냅이 켜져 있으면 4 px 단위
  • 커서가 방향에 맞게 바뀜 (↔ ↕ ⤡ ⤢)

Selecting shows 8 blue handles (4 corners + 4 edges). Drag any of them to resize; left/top handles also move the widget.

  • Minimum 8 × 4 px
  • Stays inside the 320 × 170 screen
  • 4 px steps when Snap is on
  • Cursor changes per direction (↔ ↕ ⤡ ⤢)

6-3. 정렬 가이드 Alignment guides

위젯을 이동하거나 팔레트에서 모듈을 끌어올 때, 다른 위젯의 왼쪽·가운데·오른쪽 / 위·중간·아래와 화면 중심에 4 px 이내로 접근하면 빨간 점선이 나타나고 자동으로 맞춰집니다.

  • 여러 위젯이 같은 축에 있으면 가이드가 여러 줄 표시됩니다.
  • 드래그를 놓으면 가이드는 사라집니다.
  • 크기조절 중에는 가이드가 표시되지 않습니다.

While moving a widget (or dragging from the palette), edges and centers snap to other widgets and to the screen center within 4 px, with red dashed guides.

  • Multiple guides appear when several widgets share the same axis.
  • Guides disappear on drop.
  • Guides are not shown while resizing.

6-4. 확대/축소 Zoom

  • 툴바의 확대 슬라이더: 50% ~ 200% / Zoom slider 50–200%
  • 기준점 선택: 중앙 또는 좌상단 / anchor: center or top-left
  • Ctrl + 마우스 휠로도 조절 / Ctrl + wheel
  • 설정은 브라우저에 기억됩니다 / remembered in the browser
Tip: 200%에서 미세 조정, 50%에서 전체 균형 확인 / fine-tune at 200%, check balance at 50%.

19. FAQ19. FAQ

Q. 글자 좌표가 드래그한 위치와 다르게 보여요.Q. The text does not sit where I dragged it.

오른쪽 정렬(r)은 글자가 박스의 오른쪽 끝에 붙기 때문입니다. 속성에서 Align = l로 바꾸면 드래그한 위치에 그대로 놓입니다.

Right alignment pins the text to the right edge of the box. Set Align = l in Properties to make the drag position match.

Q. 저장했는데 화면이 그대로예요.Q. I saved, but the screen did not change.

① UI List에서 활성 표시가 붙은 이름이 맞는지, ② 저장 직후 상태 문구가 저장+적용됨으로 바뀌었는지 확인하세요. 그대로라면 한 번 더 라디오에 저장하면 됩니다.

Check the active name in UI List, and confirm the status line shows saved+applied. Save again if needed.

Q. 위젯이 안 보여요.Q. A widget is not visible.

① Hide가 켜져 있는지, ② 모드 마스크가 현재 모드와 맞는지, ③ 다른 위젯에 가려져 있지는 않은지 확인하세요.

Check Hide, the mode mask, and whether another widget covers it.

Q. 128개 제한에 걸렸어요.Q. I hit the 128-widget limit.

128개는 화면 한 장 기준입니다. FM·AM·SSB는 서로 다른 화면이므로 각각 128개까지 쓸 수 있고, 세 화면을 합쳐서 세는 것이 아닙니다.

모듈 하나는 위젯 여러 개로 이루어집니다. 예를 들어 Header + Wi-Fi는 배경·시계·Wi-Fi·전압·시그널·배터리·구분선까지 7개, RSSI / SNR은 6개입니다. 모듈 20개를 놓으면 대략 100개를 넘습니다.

줄이는 방법: ① 쓰지 않는 Line(구분선)과 장식용 Rect 삭제 → ② 두 줄짜리 텍스트를 하나로 합치기 → ③ 필요 없는 모듈 제거. 현재 개수는 오른쪽 속성 패널의 items: 값으로 확인할 수 있습니다.

The limit is 128 per screen. FM, AM and SSB are separate screens, so each one gets its own 128 — they are not added together.

A single module is made of several widgets. Header + Wi-Fi is 7 widgets (background, clock, Wi-Fi, voltage, signal, battery, divider) and RSSI / SNR is 6. Twenty modules already exceed 100 widgets.

How to reduce: ① delete unused Line dividers and decorative Rect panels → ② merge two-line text into one → ③ remove unneeded modules. Check the current count in the Properties panel (items:).

Q. 새로고침하면 작업이 사라지나요?Q. Do I lose my work when I refresh?

네. 에디터는 브라우저에 작업 내용을 저장하지 않습니다. 작업 중간중간 라디오에 저장하거나 다운로드로 백업하세요.

Yes. The editor has no local storage. Save to the radio or download the project.

Q. 가로 패널에서 항목이 잘려 보여요.Q. Items are cut off in a horizontal panel.

가로 패널은 폭에 맞춰 한 항목씩 스크롤합니다. 폭을 넓히면 더 많이 보입니다.

Horizontal panels scroll one item at a time. Widen the panel to show more.

Q. Signal icon이 안 보여요.Q. The Signal icon is not showing.

Wi-Fi가 연결되지 않으면 표시되지 않습니다(의도된 동작). AP/STA/스캔 상태에서만 보입니다.

It is hidden while disconnected — by design. It appears in AP, STA and scanning states.

Q. 색을 바꿨는데 일부만 바뀌어요.Q. Only some colors changed.

위젯마다 색상 키가 지정되어 있습니다. 팔레트 값은 키를 쓰는 위젯에만 적용됩니다.

Each widget references a palette key; only widgets using that key change.
