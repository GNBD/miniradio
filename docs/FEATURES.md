# ATS Mini 기능 벤치마크 / 로드맵

공식 펌웨어(esp32-si4732/ats-mini)의 **기능만** 참고하고 코드는 복제하지 않는다.
모든 구현은 miniradio 자체 설계/코드로 작성한다.

범 례: `O` 구현됨 · `△` 부분 구현 · `X` 미구현 · `+` 자체 추가 기능

## 4. 자체 추가 기능(+)

- 값 슬라이더 + 라이브 적용
- 메뉴 표시 스타일 5종
- 밴드별 주파수 영구 기억
- RDS 라디오텍스트 마퀴
- (예정) 즐겨찾기 이름, 퀵 프리셋, 신호 히스토리

## 5. 구현 단계

1. **기반** (완료): 수신/저장/메인 UI/슬라이더/라이브 적용
2. **조작** (진행): Seek 모드, 직접 입력, VFO A/B, Scan
3. **시스템** (진행): CPU 클럭, Wi-Fi AP(TX 14), 시간/절전
4. **연결**: 웹 UI(상태/메모리/설정), NTP, 스크린샷, 원격 제어
5. **고급**: EiBi, BLE, OTA, DSP 패치, 테마/레이아웃
6. **자체 확장**: 메뉴 스타일 고도화, 신호 그래프, 사용자 프리셋 이름

> 원칙: 공식 펌웨어의 소스는 참고/복사하지 않고, 문서화된 동작(사용자 매뉴얼, AN332)만 근거로 자체 구현한다.
